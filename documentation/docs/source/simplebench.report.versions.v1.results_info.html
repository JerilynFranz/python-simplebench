Bases: BaseResultsInfo

An immutable class representing the results-info object for V1 reports.

This class encapsulates the structure and validation logic of the results-info section.

Initialize a Results v1 instance.

The input parameters are validated, converted to immutable types as needed, and stored as private attributes that are accessible via read-only properties.

Parameters:

  • group (str) – The group name of the results.

  • title (str) – The title of the results.

  • description (str) – The description of the results.

  • n (float) – The complexity analysis n value.

  • n – The n value.

  • variation_marks (VariationMarksType) – The variation marks mapping.

  • metrics (MetricsObject) – The list of metrics.

  • extra_info (CoreDataMappingType) – Additional information.
