Map a git command exit code to a CommonCode enum value.

This is a two-step translation: 1. The numeric code is mapped to its command-specific name (e.g., 128 -> “NOT_A_REPOSITORY”). 2. That name is then mapped to a CommonCode member.

run(
cmd: Sequence[str],
cwd: Path | None = None,
) → str[source]🔗

Run a git command and return its output.

If cwd is None, uses the current working directory set either by git_cwd() or os.getcwd() if git_cwd() is None.

The cwd parameter allows overriding the git working directory while executing the command but does not change the git_cwd() setting.

Basically it allows running git commands in different directories without changing the Git object’s working directory state

Precedence for working directory: 1. cwd parameter if provided 2. git_cwd() if set 3. Current working directory (Path.cwd())

Parameters:

  • cmd – List of command arguments for git.

  • cwd – The working directory to run the command in. If None, uses the current working directory.

Returns:

The command output as a string, or None if an error occurred.

Raises:

  • SimpleBenchTypeError – If cmd is not a sequence of strings or if cwd is not a Path or None.

  • SimpleBenchRepositoryActionFailedError – If the command fails.

  • SimpleBenchSubprocessExecutableNotFoundError – If the git command is not found.

validate_available() → None[source]🔗

Validate that the ‘git’ command line tool is available.

This is done by calling is_available() and raising an exception if not available. It is more-or-less a ‘backstop’ validator for other git functions to ensure they are only called when git is available.

Raises:

  • SimpleBenchSubprocessExecutableNotFoundError – If git is not available.

  • SimpleBenchRepositoryActionFailedError – If the test ‘git version’ command fails.

  • SimpleBenchNotARepositoryError – If not inside a git repository.

validate_is_repo(
cwd: Path | None,
) → None[source]🔗

Check if the current directory is inside a git repository.

This is done by calling is_repo() and raising an exception if not in a repo.

Normally, code interacting with git repositories should check for repository presence via calling is_repo() before calling any other git-related functions.

It is more-or-less a ‘backstop’ validator for other git functions to ensure they are only called when git is available and from inside a valid git repository.

Parameters:

cwd – The working directory to check. If None, uses the current git_cwd or os.getcwd().

Raises:

  • SimpleBenchNotARepositoryError – If not inside a git repository.

  • SimpleBenchSubprocessExecutableNotFoundError – If the git command is not found.

  • SimpleBenchRepositoryActionFailedError – If the command fails.
