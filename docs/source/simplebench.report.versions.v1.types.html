class simplebench.report.versions.v1.types.CPUInfoData[source]🔗

Bases: dict

Typed dictionary for V1 CPUInfo data used as INPUT.

This type is lenient, allowing type, version, and hash_id to be omitted.

Parameters:

  • arch (str) – The CPU architecture.

  • bits (int) – The CPU bitness (e.g., 32 or 64).

  • count (int) – The number of CPU cores.

  • arch_string_raw (str) – The raw architecture string.

  • brand_raw (str) – The raw brand string.

  • hash_id (str) – (optional) The unique hash identifier for the CPU information.

  • type (str) – (optional) The type identifier for the block.

  • version (int) – (optional) The version of the block’s data structure.

class simplebench.report.versions.v1.types.ValueBlockDict[source]🔗

Bases: dict

Typed dictionary for the JSON representation of a V1 ValueBlock (OUTPUT).

This type is strict, requiring type and version to be present and guaranteeing that value is a float. The timer field remains optional.

Parameters:

  • type (str) – The type identifier for the block.

  • version (int) – The version of the block’s data structure.

  • semantic_type (str) – The semantic type of the value.

  • unit (str) – The unit of the value.

  • scale (float) – The scaling factor for the value.

  • value (float) – The numeric value of the block (guaranteed to be float).

  • timer (str) – (optional) The name of the timer associated with this value.
