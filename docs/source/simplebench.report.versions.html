simplebench.report.versions package🔗

JSON report versioned classes.

This module provides functionality to manage different versions of JSON report schemas, metadata, results, and statistics. It includes validation for version numbers and dynamic retrieval of the appropriate class implementations based on the specified version.

var CURRENT_VERSION:

The current JSON report version number.

simplebench.report.versions.CURRENT_VERSION: int = 1🔗

The current JSON report version number.

simplebench.report.versions.json_class(
version: int,
class_type: T,
type_tag: ErrorTag,
unsupported_tag: ErrorTag,
) → T[source]🔗

Get the JSON class type for a given version and class type.
